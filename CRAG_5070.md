# CRAG eval on the RTX 5070 box

Prep the Cloak folder + CRAG dataset on the 5070 machine, then run the ladder below.

## 1. Copy onto the machine

From this repo, copy the whole `Cloak/` directory:

```text
Cloak/
  cloak_config.py
  eval_crag.py
  history_aware_generation.py
  ingestion_pipeline.py
  session_manager.py
  server.py
  requirements.txt
  setup_crag_5070.sh
  run_crag_5070.sh
  .env.example
  CRAG_5070.md
```

Also copy the CRAG jsonl (~5GB):

```text
crag_task_1_and_2_dev_v4.jsonl
```

Suggested location on the 5070 box:

```bash
sudo mkdir -p /data/crag
sudo cp crag_task_1_and_2_dev_v4.jsonl /data/crag/
```

## 2. One-time setup

```bash
cd Cloak
bash setup_crag_5070.sh
nano .env   # set CLOAK_CRAG_PATH=/data/crag/crag_task_1_and_2_dev_v4.jsonl
```

`setup_crag_5070.sh` creates `.venv`, installs **CUDA torch**, Cloak deps, and pulls `qwen2.5:14b` (default) via Ollama.

Confirm GPU:

```bash
source .venv/bin/activate
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

You want `True` and the 5070 name. If false, reinstall torch with a CUDA index (see script) — CPU embed/rerank will be slow.

## 3. Run evals

```bash
source .venv/bin/activate
bash run_crag_5070.sh smoke        # quick sanity
bash run_crag_5070.sh corpus       # gold-in-pages upper bound
bash run_crag_5070.sh retrieval    # hybrid + rerank (n=100, --html)
bash run_crag_5070.sh generate     # full answers via Ollama (n=40)
# or
bash run_crag_5070.sh all
```

Override size:

```bash
LIMIT=200 bash run_crag_5070.sh retrieval
```

JSON results land in `Cloak/crag_results/`.

## 4. What to expect (rough)

| Mode | What it measures | Notes |
|------|------------------|-------|
| `corpus` | Is gold even in the pages? | Upper bound; no GPU RAG needed |
| `retrieval` | Top docs after hybrid+rerank contain gold? | Needs CUDA for speed |
| `generate` | Final answer matches gold? | Needs Ollama + LLM VRAM |

First run builds a `.lite.jsonl` cache next to the dataset so later runs skip re-stripping the full 5GB file (unless you pass `--html`, which reattaches HTML for the sample).

## 5. 5070 sizing tips

- **Default LLM:** `qwen2.5:14b` (good fit for ~12GB VRAM)
- Faster / more headroom: set `CLOAK_LLM_MODEL=qwen2.5:7b` in `.env`
- Keep `CLOAK_VISION=0` for CRAG (no figures in this harness)
- System **32GB RAM** is enough for bge-m3 + reranker + Chroma sessions

## 6. Optional: API server on the same box

CRAG does **not** need the FastAPI server. For the Windows UI against this box:

```bash
source .venv/bin/activate
uvicorn server:app --host 0.0.0.0 --port 8001
```

Point `CloakUI.py` `SERVER_URL` at `http://<5070-ip>:8001`.
