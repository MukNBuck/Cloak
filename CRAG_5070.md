# CRAG eval on the RTX 5070 (Windows)

Prep the `Cloak` folder + CRAG dataset on the 5070 Windows machine, then run the ladder below.

## 1. Copy onto the machine

Copy the whole `Cloak\` directory from this repo, plus the CRAG jsonl (~5GB):

```text
C:\cloak\Cloak\          ← code
C:\data\crag\crag_task_1_and_2_dev_v4.jsonl
```

## 2. One-time setup

Open **PowerShell as Administrator** once (needed for winget / installer), then:

```powershell
cd C:\cloak\Cloak
Set-ExecutionPolicy -Scope Process Bypass
.\setup_crag_5070.ps1
```

That script will:

1. Create `.venv` and install **CUDA torch** + Cloak deps  
2. Install **Ollama for Windows** via `winget` (or download `OllamaSetup.exe` if winget is missing)  
3. Start Ollama and wait until `:11434` responds  
4. Pull `qwen2.5:14b` (default) and `qwen2.5:7b`

Edit `.env`:

```text
CLOAK_CRAG_PATH=C:\data\crag\crag_task_1_and_2_dev_v4.jsonl
```

Confirm GPU + Ollama:

```powershell
.\.venv\Scripts\Activate.ps1
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
ollama list
```

You want `True` and the 5070 name. If CUDA is false, reinstall torch with a CUDA index (see the setup script) — CPU embed/rerank will be slow.

If `ollama` is not found after install, **open a new PowerShell** (PATH refresh) or start **Ollama** from the Start menu once.

## 3. Run evals

```powershell
cd C:\cloak\Cloak
.\.venv\Scripts\Activate.ps1
.\run_crag_5070.ps1 smoke
.\run_crag_5070.ps1 corpus
.\run_crag_5070.ps1 retrieval
.\run_crag_5070.ps1 generate
# or
.\run_crag_5070.ps1 all
```

Override sample size:

```powershell
$env:LIMIT = "200"
.\run_crag_5070.ps1 retrieval
```

JSON results land in `Cloak\crag_results\`.

## 4. What to expect

| Mode | Measures | Needs |
|------|----------|-------|
| `corpus` | Gold answer in pages? (upper bound) | CPU fine |
| `retrieval` | Hybrid + rerank hits gold? | CUDA preferred |
| `generate` | Final answer matches gold? | Ollama + VRAM |

First run builds a `.lite.jsonl` cache next to the dataset. `--html` reattaches page HTML for the sampled questions (slower, better recall).

## 5. 5070 sizing tips

- Default LLM: `qwen2.5:14b` (~12GB VRAM class card)  
- Faster / more headroom: set `CLOAK_LLM_MODEL=qwen2.5:7b` in `.env`  
- Keep `CLOAK_VISION=0` for CRAG  
- 32GB system RAM is enough for bge-m3 + reranker + Chroma

## 6. Optional: API server on this box

CRAG does **not** need FastAPI. For the other PC’s UI:

```powershell
.\.venv\Scripts\Activate.ps1
uvicorn server:app --host 0.0.0.0 --port 8001
```

Point `CloakUI.py` `SERVER_URL` at `http://<5070-ip>:8001`.

## Linux scripts

`setup_crag_5070.sh` / `run_crag_5070.sh` remain for Linux boxes; use the `.ps1` scripts on this Windows 5070 machine.
